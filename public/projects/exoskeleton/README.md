# Exoskeleton project media

The following figures were extracted directly from the supplied research PDF,
with Alessandro's authorization to display them on the website and repository:

| File | Source | Use |
| --- | --- | --- |
| `architecture.png` | Figure 3, page 3 | Project page, Home and Projects cards, social preview |
| `setup.webp` | Figure 1, page 1 | Compact project-page setup figure |

The embedded figures retain their original dimensions: 2463 × 495 and
1404 × 1614 pixels respectively. The setup figure is encoded as lossless WebP;
its decoded RGBA pixels match the PDF image. No paper text or captions were
included in the image files. Captions and alternative text are provided in HTML.

Matching copies live in `images/architecture.png` and `images/setup.webp` in
`alessandro-leanza/Exoskeleton`. Synchronize both copies when replacing media.
`ProjectMedia` retains a labelled fallback if an asset is absent and lets readers
open each available figure at full resolution. Rebuild after changing assets.

The manuscript PDF itself is not served. The public paper link points to the
earlier arXiv version, which may not contain the later results on the project page.
