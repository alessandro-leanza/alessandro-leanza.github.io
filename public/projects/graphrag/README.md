# Graph-Based RAG project media

`architecture.png` is the supplied architecture figure. It appears on the project
page, the Home and Projects cards, and the project social preview.
The public path is `/projects/graphrag/architecture.png`.

The matching source asset is `images/architecture.png` in
`alessandro-leanza/Graph-Based-RAG_RobotPlanning`. Both copies are identical.
The PNG was losslessly re-encoded to remove embedded diagram-editor metadata;
its dimensions and RGBA pixels are unchanged. Synchronize both copies and rebuild
when replacing it. Existing components retain labelled fallbacks if it is absent.

The manuscript is a separate asset from the architecture image. A public paper
URL will be configured in src/data/graphrag.ts after its sharing status is confirmed.
